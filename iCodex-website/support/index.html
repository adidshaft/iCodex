Support

Setup guide, downloads, and a way to send feedback or report issues.

Setup

  1. Download iCodex-Connect for macOS below
  2. Move it to /Applications and open it
  3. Grant Accessibility permission when macOS prompts
  4. Open Codex on your Mac so threads are available
  5. Make sure Mac and iPhone are on the same Wi-Fi
  6. Pair using the 6-digit code shown in the Mac menu bar

Troubleshooting

Mac not found

  • Confirm iCodex-Connect is running
  • Both devices must be on the same Wi-Fi
  • Check Local Network permission in iOS Settings
  • Try entering your Mac's IP address manually

Pairing fails

  • Use the current 6-digit code from the menu bar app
  • Disconnect and try pairing again from the iOS app

Actions don't work

  • Verify Accessibility permission is still granted
  • Make sure the Codex desktop app is open
